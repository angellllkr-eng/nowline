# Nowline Release Execution Layer

Release objective: define executable gates before a 1.0 compatibility claim.

Gates: parse/validate fixtures → deterministic rendering fixtures → CLI smoke tests for supported outputs → Node compatibility matrix → package/release artifact checks → LSP/extension integration → documentation/examples verification → GitHub Release artifact verification.

Syncfusion is not part of the core CLI/compiler. A future web dashboard should evaluate it separately.

No 1.0 claim until compatibility and release evidence are executable and reproducible.
